☕ CampusBrew

Coffee That Fits Your Campus Life.

CampusBrew is a quick-serve, budget-friendly coffee stand website made for students, teachers, and school staff who need a simple coffee break between classes. This project is our business website with an interactive ordering demo and a promotional video ad.

📌 About the Project

Many students can only choose between very cheap machine coffee in the school canteen and more expensive cafés outside school. CampusBrew fills that gap by offering better-quality coffee at a student-friendly price, close to where students already are.

Our feasibility plan sets the target selling price at ₱20 per cup, based on our survey finding that most respondents preferred coffee below ₱20.

Market Position
Feature	School Canteen	Nearby Café	CampusBrew
Price per cup	₱5	₱80–₱180	Target: ₱20

Convenience	Inside school	Outside school	Near or inside school
Main strength	Very cheap and fast	More variety and place to sit	Affordable and convenient
✨ Website Features
Landing page with a clear introduction to CampusBrew
Animated video ad that plays automatically when the website opens, featuring our team, a short promotional script, and an Order now button (it can be replayed with the ▶ Watch our ad button)
Menu section with four drinks, each at ₱20: Hot Coffee, Iced Coffee, Creamy Coffee, and Chocolate Coffee
About section explaining why CampusBrew exists
Competitor comparison table
Interactive demo cart where you can add drinks, remove items, and see the total calculated by Python
Demo order form with name, pickup preference, and special request
Responsive design that works on phones, tablets, and computers

Note: The order form is a school project demonstration only. No real order or payment is sent.

🛠️ Technologies Used
HTML5 and CSS3 for structure and design
JavaScript for the animated video ad
Python (PyScript) for the cart logic and order summary
Google Fonts (DM Sans and Playfair Display)
🚀 How to Run the Website
Download or clone this repository.
Open index.html in a web browser (Chrome, Edge, or Firefox).
Make sure you have an internet connection, because PyScript and the fonts load online.

The video ad will start automatically. Wait a few seconds after the page opens for PyScript to finish loading before using the cart.
